# Product Line Profitability & Margin Performance Analysis

## Project Overview
This project analyzes sales, costs, gross profit, and profit margins for Nassau Candy Distributor. The goal is to identify profitable products, compare division performance, and generate business insights to support better decision-making.

## Objectives
- Analyze overall sales and profitability.
- Compare performance across product divisions.
- Identify high-profit and low-margin products.
- Understand product cost and gross margin patterns.
- Create an interactive dashboard for business analysis.

## Dataset
The dataset contains sales transaction details, including product names, divisions, sales, costs, quantities, order dates, and regional information.

## Technologies Used
- Python
- Pandas
- NumPy
- Plotly
- Streamlit
- Jupyter Notebook

## Key Performance Indicators (KPIs)
- Total Sales
- Total Cost
- Gross Profit
- Gross Profit Margin
- Units Sold
- Profit per Unit

## Dashboard Features
- Overall business performance overview
- Product and division profitability analysis
- Cost and profit margin comparison
- Profit concentration analysis
- Interactive product exploration
- Filters for product, division, and order date
- Data export for further analysis

## Installation and Execution

1. Clone or download this repository.
2. Install the required libraries:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the Streamlit application:

   ```bash
   streamlit run app.py
   ```

4. Open the local URL displayed in the terminal to explore the dashboard.

## Expected Outcome
The project provides an interactive view of product profitability, highlights business performance patterns, and helps identify opportunities to improve profit margins and product strategy.
